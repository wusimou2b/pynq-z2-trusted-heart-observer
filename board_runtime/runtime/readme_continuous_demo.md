# 25/25Hz＋5fps 持续演示

本目录从2026-11-01冻结成功版新增入口，632个原文件逐字节保留。
HDMI显示视频、心率数字及选路；浏览器显示四条曲线和正常停止按钮。

1. 打开 ContinuousDemo25.ipynb，依次运行四个代码单元，不使用 Run All。
2. 第一单元无硬件PS短检查；第二单元20秒视频资格检查，确认动态画面及收尾正常。
3. 第三单元准备浏览器显示。看到绿色绘图就绪后，保持该单元输出可见。
4. 手指放稳后运行第四单元，输入 RUN-DEMO-CONTINUOUS25。预热另计，正式采集不会在60秒自动结束。
5. 结束演示时，点击第三单元输出里的“正常停止并导出”。第四单元忙碌时按钮仍可提交请求；不要用中断内核代替正常停止。
6. 等待“已停止并导出”和第四单元返回。回传 demo-continuous-results.zip 及 continuous-results.zip；若故障/停止未完成，保留输出和原目录，不自动重跑或启动另一个硬件入口。

本次仅在上一持续版上将调度观测记录容量2048扩到8192，启动多预分配384KiB；每拍call和收尾report代码保持一致。取消原Trace的60秒定时停止继续沿用。原epoch校验、全部算法、700点预热、GC、40ms事务/整拍相关保护、1秒新鲜度、5fps、队列与PS自然退出/DMA收尾均保留。
8192次调用按25Hz约5分28秒，其他固定观测缓冲可能更早达到上限。第一轮在约3分钟正常手动停止，不宣称无限时长；不丢弃观测记录或取消满载保护。
原固定审计缓冲（含65536行Trace）及其满载保护也保留；达到保护或发生故障仍会停止。这是取消60秒上限的持续演示候选，不是无限时长/长期稳定性验收。
目录里历史命名含 live60/status60 的文件保留为依赖与审计出处；本次实际运行模式以 demo-continuous-manifest.json 与 demo-continuous-owner.json 为准。
