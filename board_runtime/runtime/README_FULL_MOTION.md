# 原190秒基线：心率＋视频运动＋MPU6050融合

只运行 FullMotion25.ipynb。旧成功目录和失败证据保留。本目录为独立集成候选，
不是已通过的实测版。原340文件逐字节保留，实际心率核心/PS加载/IIC/GC/退出
顺序不变；不使用失败版PS-first入口或逐寄存器计时。

## 三个单元

1. 无硬件身份校验和原PS短退出；不放手指，不加载电路/相机。
2. 准备心率面板和“正常停止并导出”按钮，等绿色就绪。
3. 确认其它任务已收尾，摄像头/HDMI已连接，MPU固定于绿框中同一只手，
   放稳手指。输入 RUN-FULL-MOTION25，手动启动。会替换PL，不自动恢复旧电路。

正式运行持续到正常停止，没有60秒强制停止。先放稳观察心率及动态视频；
若需要动作观察，按HDMI DO提示静止/轻动/强动/静止各15秒，之后可继续静止。
不要用中断、关内核或重复运行代替停止。点击第二单元的正常停止按钮后，
等待全部收尾和ZIP；停止未完成不得启动其它入口。

## 完整功能与边界

25/25Hz心率和5fps动态视频同时运行；PL完成YUYV转色、灰度降采样、
4×3帧差统计和运动像素计数。固定候选规则给出VIDEO三档；MPU沿用原
25Hz采集及已处理运动结果，无额外IIC读取或逐拍IPC。按源时间配对并融合，
屏幕显示IMU/VIDEO/FUSION，保存原始统计、源时间、冲突/缺失原因。
两路冲突或过期可为UNKNOWN，不把未知写成静止。融合暂不接管原心率选路。
三档准确率仍需对照动作验证，不把“功能接通”写成准确率通过。

为移出已观察到的首帧冷分配，正式心率开始前通过原HDMI API提交4幅黑底
PREPARING画面。它们不经过空间核、不推进帧差历史、不计入正式视频数；
所有权和三DMA停稳后释放仍用原实现，不直接操作缓存指针。

700点预热、180秒启动/60秒PS READY、100ms状态/1秒结果新鲜度、2秒父进度、
原队列/GC、PS join(1)/terminate/join(1)均不变。不承诺消除长期积压。
