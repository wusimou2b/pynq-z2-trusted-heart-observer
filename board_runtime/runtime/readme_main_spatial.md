# PL心率主链＋新版视频运动＋原混合显示

本包保留原成功版全部388文件，另外增加PL主链接入和新联合bit/HWH。原版目录不替换。
25Hz采集、25Hz处理、5fps视频；700点预热、60秒READY、180秒启动、1秒处理/退出/新鲜度和20ms主核事务保护保持原值。
HDMI继续显示视频、运动/融合状态和心率文字；浏览器继续显示四条波形及正常停止按钮。
采集配对与视频/MPU规则均沿用原版，本包没有接入离线校时候选。

三个代码单元按顺序各运行一次。第一单元仅验证新PS目标的无硬件启动和自然退出；第二单元准备浏览器绘图和正常停止；第三单元经手动确认后加载本包新电路并开始采集。
首次联合验证放稳手指，运行约60秒后点击第二单元的“正常停止并导出”。后续持续测试仍使用同一正常停止流程。失败保留，不自动重试，不用中断内核代替收尾。
本包会替换PL，并且不会自动恢复原Overlay。启动前需确保其他板端任务已结束并释放PL资源。

本地检查与上板测试分开：交付前已要求联合100MHz时序、接口/CDC、核源及软件接入验证；本包还未证明传感器/视频并发下的持续实时表现。
为解决联合电路的建立时间违例，新候选只将浮点ROUND溢出条件改为等价并行比较；原版核源不修改。实际RTL穷举131072种指数/舍入进位组合，状态机、算法数值和流水周期保持不变，证据记录在hardware/main-spatial-integration.json内。
迁移主核不再通过已锁住的旧NLMS邮箱读取快照。最终独立核对主核实际accepted/completed计数，保留1秒新鲜度等全部安全判定。
日志pl_latency_cycles=0表示该主链协议不返回独立NLMS周期；不得把0视为测得零耗时。pl_call_ns记录整条主核调用墙钟，另保留主核计数和协议身份。
