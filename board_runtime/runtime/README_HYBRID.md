# 浏览器四曲线＋HDMI视频和心率

运行 HybridDisplay25.ipynb。三个代码单元依次各运行一次，同一个内核。

1. 文件核对和原PS短退出验证：无硬件。成功后再执行第二单元。
2. 准备浏览器四条曲线与“正常停止并导出”按钮；等待绿色就绪。
3. HDMI OUT、USB摄像头和传感器连接好，其他板端任务已结束，放稳手指。
   输入 `RUN-HYBRID25` 启动。会替换PL，不自动恢复旧Overlay。

浏览器显示原四条曲线。HDMI保持原完整视频、绿框及视频/MPU融合信息，
底部仅有心率数值和选路/状态。数值过期、接触无效或故障时显示N/A。
25/25Hz＋5fps；700点预热、GC、队列、原1秒新鲜度和退出策略均保留。
前60秒运动提示继承原版，之后继续运行；根据本次测试安排选择动作。

结束时返回第二单元，点击“正常停止并导出”，保持页面打开，等待收尾。
按钮通过浏览器写停止请求，第三单元运行期间仍可使用。避免用内核中断代替正常停止。
结果 `hybrid-display-results.zip`。本地检查不能替代板端观察；本版尚未板测，
也不宣称消除了长时间积压、所有N/A或完成准确率/DDR/完整V3B验收。

本目录保留379个原完整运动版本文件，仅新入口增加文字显示。旧目录及其结果不变。
