# Lean联合60秒：只增加退出记录

本目录保留原Lean319文件字节、Native100及其已准备的ARM二进制。复用已核验的原短测和1505点普通回放证明，不再运行纯回放。当前仍不是退出修复、准确率、DDR或完整V3B验收。

## 手动操作

相机、HDMI与传感器接好；另一分支及其它板端任务先结束。不要并发使用Overlay、IIC或采集入口。

1. 打开本目录 `JointExit60.ipynb`，运行第一代码单元：只读身份/证明/实际解释器校验并准备浏览器Canvas，不访问传感器/电路或启动视频。不运行原LeanPS60或其它旧Notebook。
2. 等Canvas绿色，放稳手指。运行第二代码单元，输入 `RUN-JOINT-EXIT60`。正式25/25Hz＋5fps联合60秒，启动及预热另计，原180秒启动、700点及60秒PS-ready保护不变。
3. 等原收尾和附加导出完成，回传 `joint-exit60-results.zip`；说明HDMI是否全程动态。失败保留全部输出和结果，不自动或手动重复本目录。

## 变更边界

原算法、IIC、GC策略、队列和新鲜度保护不改，仍为原 `join(1) → 必要时terminate → join(1)`。退出观察不增加等待、close、逐拍IPC、逐拍记录或回放计算；只给实际处理线程关闭和子进程退出路径增加原固定64槽时钟/finalizing记录。该观察有少量分配和调度扰动。

只有实际所有者和实际PS退出均有证明才读取共享表。自然退出与原forced/exitcode、硬件释放、原联合完成及观察完整分列；forced=True且exitcode=0也保留为原自然退出失败，不能据此声称SIGTERM杀死。`finalizing=True`不是模块清理完成，未完成区间不能指认具体库。

新ZIP保留原Lean联合ZIP（含原Native结果）和两份未经修改的ARM证明。报告不覆盖原门或将失败改为通过。缺退出证明时保留引用和原结果，不自动启动其它入口。
