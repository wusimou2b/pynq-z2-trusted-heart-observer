# 首次真实相机4×3空间特征采集

这是采集新PL特征，不是新三档识别或心率联合验收。旧成功心率版和旧分类器不覆盖；本轮HEART OFF，不运行PPG/IMU/心率PS。

1. 在全新`v3b25 spatial camera`目录运行；确认其它硬件任务已结束且安全收尾，不要中断另一分支的任务。
2. 接好USB相机与HDMI屏幕，保持此前固定机位、距离和光照。先把手放到原中央绿框对应位置；本轮不额外预览或保存图像。
3. 打开SpatialCamera60.ipynb，第一单元仅检查文件/静态资格，不加载电路。第二单元输入`RUN-SPATIAL-CAMERA`，允许唯一所有者重新加载已静态通过的新空间统计电路，替换当前PL且不自动恢复旧Overlay。
4. 看到HDMI的DO提示后依次做：0～15秒静止；15～30秒小幅缓慢轻动；30～45秒明显更快/更大幅度强动；45～60秒恢复静止。手尽量留在绿框内，勿移动相机。若开头仍需调整，回传时如实说明。
5. 屏幕应有动态画面、4×3绿框网格、更新序号及FEATURES ONLY / HEART OFF。changed为运动像素比例，max-block-mean是最大块平均帧差；它们不是预测档位。DO只是动作要求，不是识别结果。
6. 等待自然结束与收尾，回传`spatial-camera-results.zip`和完整单元输出，并说明画面/序号是否全程更新、动作是否按提示完成。失败保存，不在同目录重跑。

目标5fps、正式60秒、原180秒启动、1秒PL传输/HDMI提交、250ms帧对和年龄保护均保留；原三DMA/缓冲/真实锁安全收尾顺序不变。QUARANTINE或收尾未确认时保留页面/内核和结果，不强杀、不启动其它入口。若日志writer仍活跃，ZIP只导出报告与身份，不读取活跃JSONL；原目录中的记录保留。

固定T=8是abs(gray_now-gray_previous)>=8的像素计数门限，不是静止/轻动分界。每块40×40、1600像素，全ROI19200像素；12块行优先。光照变化也可产生计数，目前没有光照补偿或手部识别。

日志全保留，首帧、缺号、间隔/年龄失效为不可用N/A而不是静止0。四段前2秒单列transition，不事后删样本或把动作提示当真实标签。只保存标量JSONL和摘要，不写摄像头图像/视频；仅原前两帧保存在有界RAM，硬件停止确认后核颜色/旧ROI/新分块参考再释放，不能称为全程逐像素验证。

新bit/HWH与8图静态通过的一对完全相同；其原spatial-artifacts.json的静态发布声明保留，新相机包以固定资格证据授权这次有限试验，不扩展为其它硬件/DDR验收。会话完整、5fps观测、有效覆盖和实际屏幕观察分别记录，不因为自然结束就宣布三档识别/准确率/完整V3B通过。
