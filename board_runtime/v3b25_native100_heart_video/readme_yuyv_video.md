# PL颜色转换与显示写回：独立20秒视频首测

本包含新bit/HWH。唯一所有者手动加载新电路一次，保留NLMS及视觉核；此次只启动相机、PL视频路径和HDMI，不启动心率或传感器。退出不会恢复旧Overlay。

先让其他板端任务完成并实际收尾，固定相机USB和HDMI OUT/显示器供电。无需放手指。打开本目录YuyvVideo.ipynb，第一单元冷校验；第二单元输入RUN-YUYV-VIDEO。启动另计，正式20秒、目标5fps。请全程观察屏幕动态画面与序号，可缓慢移动物体。正常结束停止HDMI，屏幕恢复无信号。

流程：USB原始YUYV→一次输入CMA复制→PL颜色转换→同时计算原ROI与DMA写回BGRX显示帧→直接提交HDMI。小范围标注在同一帧上进行。PYNQ显式32位BGR颜色格式；请求非缓存帧，但不凭申请参数或coherent标志推断物理属性。noncoherent帧写前flush、完成后invalidate、标注后由HDMI原驱动flush。不会手改coherent。

首两帧原始数据/未标注写回图像仅在RAM暂存，实际硬件收尾确认后核完整颜色像素与原ROI数值，随后清除；不保存相机图像。结果yuyv-video-results.zip记录全部帧协议、耗时、收尾和两帧对照。软件提交成功不证明屏幕已显示；请回报实际观察。

故障保留，不自动重试。收尾未确认时显示QUARANTINE，进程保留CMA和真实硬件锁；不要关闭内核、重复启动、换Overlay或强杀。把输出发回。Notebook外层等待120秒并请求停止，额外等待10秒；无法保证强行打断底层驱动调用，不自动强杀。

这是新视频路径首测。25Hz心率保底、共同60秒、IIC交接和PS自然退出、手部动作标定仍需后续完成；本次不代表完整V3A/V3B、DDR、15fps或准确率验收。
