# 独立相对路径演示包

入口：`runtime/ContinuousDemo25.ipynb`。整体复制本目录，保留 `runtime` 与 `v3b25 native100 heart video` 的同级关系；外层目录可改名或移动。不要只复制 runtime。

此副本来自冻结 retry6，不覆盖任何原目录。仅改原生库准备报告的路径解析、本机无硬件检查的依赖位置，以及按Notebook所在目录解析停止按钮路径；关联 manifest 与身份 pin 已重新封装。心率、视频、MPU 融合、混合显示、25/25Hz＋5fps、持续手动停止、容量8192及原保护保持不变。

依次运行四个单元；前三个是短退出检查、20秒视频检查、显示准备。第四个由用户启动持续采集；通过第三个单元的“正常停止并导出”按钮停止。失败保留结果，不自动重试。

`python3 -B verify_portable.py` 可从任意工作目录校验文件，不访问硬件。板端仍需原有 PYNQ/Python 系统依赖和设备；这不是跨平台运行包。Windows 离线仿真/编译工具安装路径、系统设备路径及历史构建报告不作为运行依赖搬迁；它们按原记录保留。

原 ARM 原生库未重编译。准备报告是原证明的路径派生副本；原文保存在 provenance/native-prepared-original.json。旧报告中的通过标志属于原实验，不代表本次新实采已通过。新结果在 runtime 内生成。
