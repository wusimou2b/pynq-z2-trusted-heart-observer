# 设计报告与协作记录

本目录各保留一套 Word 和 PDF：

- [七章设计报告（Word）](materials/technical_report_anonymous.docx) 与 [对应 PDF](materials/technical_report_anonymous.pdf)：依次覆盖选题背景与创新、设计原理和功能框图、软硬件划分与接口、优化和资源对比、大模型协作、技能包提炼、复现说明。原小节编号及图号用于保留原文交叉引用，工程成果和参考文献列在附录。PDF 由此 Word 导出。
- [大模型协作记录（Word）](materials/llm_collaboration_record_anonymous.docx) 与 [对应 PDF](materials/llm_collaboration_record_anonymous.pdf)：保留提示词、回答、纠错和验证边界。PDF 由此 Word 导出。

源码、运行路径恢复、已核验的板端环境与未验证的全新 SD 系统边界，见项目根目录 [readme.md](../readme.md) 和 [board/readme.md](../board/readme.md)。本包不含海报；该决定不替代赛事其他阶段的材料要求。
