# 可信心率观测系统使用与核验说明（公开入口版）

本文件保留报告配套的历史操作与80.652秒联合记录。当前下载部署入口为 `board_runtime/runtime/ContinuousDemo25.ipynb`，须完整复制两同级运行／原生依赖目录；最新33.193811316秒、832条、166帧实测与环境边界以[当前板端说明](../../board/readme.md)及[根README](../../readme.md)为准。旧记录不与本次记录混用。

作品名称：基于FPGA的个体健康趋势预警——面向多模态感知的可信心率观测系统。

工程、八项Skills与构建资料入口：[工程与Skills仓库](https://github.com/wusimou2b/pynq-z2-trusted-heart-observer)。运行文件与依赖身份以工程manifest和仓库README为准。

本说明覆盖与工程交付包一致的板端环境中的装配检查、演示操作、正常停止和结果核验。系统在本地完成PPG心率处理与视觉、惯性运动观测；Skills用于研发和证据整理，设备运行不依赖大模型推理。

## 2. 装配与连接检查

主机支架、相机立柱与主板托盘组织板卡、屏幕和相机。MAX30102与MPU6050没有独立传感器外壳，使用黑色绝缘胶带和魔术贴固定。保持现有绝缘、固定与接线，使手指自然接触MAX30102光学面；检查屏幕定位、托盘隔离柱、相机连接、SD卡及线束净空。无需为材料拍摄拆卸整机或揭除绝缘。

传感器共用IIC连接：SDA接Arduino接口J3-10／P16，SCL接J3-9／P15，模块供电3.3V并共地，MAX30102地址0x57、MPU6050地址0x68；模块端以SDA、SCL、VCC/VIN、GND丝印及工程接线图核对。相机接USB，屏幕接HDMI，并准备板卡供电和本地网络。连接依据见技术报告图5a、图5b；总体结构见图1、图2，机械模型见图3—图5，实物与接线见图10—图13a。

## 3. 四个代码单元的操作顺序

打开 `ContinuousDemo25.ipynb`，从上到下分别运行四个代码单元，不使用“Run All”。这些步骤由操作者在板端执行。

| 单元 | 操作 | 继续前确认 | 导出或界面 |
|---|---|---|---|
| 1：PS检查 | 运行第一代码单元，完成`check(expected)`与`short(expected)`。 | 入口及依赖身份检查完成，PS短检查正常返回。 | `demo-short-results.zip` |
| 2：视频检查 | 确认其他硬件入口已经正常停止；在提示处输入`RUN-DEMO-VIDEO20`。 | 20秒视频检查中画面及序号动态更新，检查结束后资源释放完成。 | `demo-preview20-results.zip` |
| 3：浏览器准备 | 运行第三代码单元，准备曲线和停止按钮。 | 看到绿色绘图就绪，保持该单元输出可见。 | 四路曲线及“正常停止并导出”按钮 |
| 4：联合采集 | 固定传感器、稳定手指；在提示处输入`RUN-DEMO-CONTINUOUS25`。 | 已完成视频检查且浏览器绘图就绪；预热后进入采集。 | HDMI观测、浏览器曲线和采集记录 |

联合采集期间保持相机和屏幕供电，仅保留一个硬件资源所有者，不另开采集或Overlay入口。采集由界面停止请求结束，容量与故障保护仍然生效；缓冲容量换算不能替代相应时长的实测结论。

## 4. 观察界面与正常停止

浏览器显示四路波形以及接触、质量、路由和心率状态。HDMI显示相机画面、区域网格、心率与运动标签。视觉和惯性用于运动背景观测，不改变心率数值；图16、图17中的`SHADOW ONLY`对应这一旁路关系。图14为采集中的浏览器示例，图15保留停止后的历史曲线及状态。

条件不足时，系统撤回数值并保存原因。出现`N/A`时，结合接触、SQI、有效IBI、峰龄、来源新鲜度和停止状态判断，不把历史曲线或旧读数当作当前有效结果。

结束时点击第三单元输出中的“正常停止并导出”，等待第四单元返回并完成导出。第四单元忙碌时停止按钮仍可提交请求，不用中断内核代替正常停止。若界面报告故障、检查未通过或停止未完成，保留输出、原目录和结果文件供核验，不立即另开硬件入口或自动重跑。

导出结果包含 `demo-continuous-results.zip` 和 `continuous-results.zip`。停止请求、页面结束与资源释放是不同证据，应确认工作进程退出和所占资源释放后再开始其他硬件会话。

## 5. 历史联合运行测试与证据核对

联合运行测试在PPG/IMU 25Hz、视频目标5fps条件下记录约80.7 s的采集窗口，统计如下。

| 检查项 | 保存记录中的结果 | 核验含义 |
|---|---|---|
| 原始、处理与保存 | 原始2021条，处理2021条，保存2021条 | 分别检查计数及尾部记录是否对应。 |
| 配对与未配对 | 配对2020条，未配对1条 | 未配对记录保留原因，数值发布许可为否。 |
| 视频输出 | 完成403帧，漏目标槽0 | 完成提交的帧数与抓取、选择、在途帧等计数分开解释。 |
| 停止 | 用户手动停止 | PS、视频及所有者进程退出码为0。 |
| 资源 | 记录了相机、缓冲、HDMI及租约释放 | DMA停止状态和错误位与进程退出分别核对。 |

核验时保留原始和处理CSV、视频/显示日志、进程退出回执及资源释放记录。对心率输出同时检查候选来源、发布许可与源新鲜度。技术报告3.3分别给出联合运行、同输入组件对照和PL资源时序；软件回放、真实PL、真实采集和组件计时具有不同测量范围，不能互相替代。

上述计数用于说明这段记录中的处理、保存和保护行为，不等于心率准确率或长期稳定性。汇总检查结论按原文件保留，不能因若干分项成立而改写为所有验收项通过。
