# Publication scope

The repository contains the reviewed design source, eight full Skills, current technical documents and a separately sealed public LIVE tree. The LIVE manifest verifies all runtime source, Notebook source identity and fixed assets. Known result paths are explicit and cannot replace listed code; original private numerical replay remains separate.

No old Git objects, private raw physiological CSV/ZIP, author-email audit JSON, identity authorization forms, private chat dumps, internal document backups or superseded video are included. Third-party license notices are retained. The public account URL and legal project attribution are not a claim of Internet anonymity.

The Python/JS software checks do not establish ARM loading, PL download, live acquisition, clean build or new board qualification. See the actual scope in reproduction/public_live_software_checks.json.
